# 金秤 · 贵金属交易工作台

本地贵金属行情分析与模拟交易平台（开源外围）：行情、回测、信号、模拟盘、风控、插件机制、
respire 记忆插件——**全部开源**；产品灵魂 **AI agent 核心（agentd）为闭源二进制**，见 Release。

- 纯开源即可用：K 线、画线、回测与参数优化、信号、模拟盘、风控、插件——不依赖闭源件
- 安装闭源 AI 核心后追加：AI 对话（pi agent，可对话改产品）、行为教练、记忆智能判重、
  研判连续剧、到价/事件联动——核心崩溃不影响产品主服务，还能自动拉起它
- 不连券商、不下真实委托、不上传数据；只监听 `127.0.0.1`

## 快速开始

```bash
# 构建（需 Rust 1.75+）——开源部分独立可构建
cargo build --release
cp target/release/goldscale .

# 启动（自动检测：装了闭源 AI 核心就双进程，没装就只起产品）
bash start-all.sh
```

浏览器打开 `http://127.0.0.1:8787`。**没装 AI 核心时**：行情/回测/信号/模拟盘全部照常，
AI 对话与教练入口会提示不可用；到 [Releases](../../releases) 下载 `goldscale-agentd`
解压到本目录，再跑一次 `start-all.sh` 即获完整 AI 能力。

## 闭源 AI 核心（goldscale-agentd）

产品与 agent 分离的"灵魂层"，以**闭源二进制**分发（[Release 下载](../../releases)）：

| 能力 | 说明 |
|---|---|
| agent 托管 | 每会话常驻 pi agent；Origin 白名单闸门（仅本机页面） |
| 自愈监督 | 每 10 秒探产品健康，连挂 3 次自动拉起——agent 不随产品崩 |
| 对话改产品 | 对话里说「加/改某功能」，agent 自己改插件、自检、上线（git 可回退） |
| 记忆网关 | 记忆读写收口：写必先判重，高相似起 agent 裁决改/并/挂 |
| 能力任务口 | `/api/agent/task`：回测解读、优化建议、亏损归因、研究总结、周报 |
| 行为教练 | 产品事件（亏损/连赢/到价）→ 2 秒内生成人话教练动态 |
| 产品工具 | pi extension：对话直接读行情/持仓/策略 |

```bash
# 安装（解压到项目根后）
bash start-all.sh   # 自动带起 agentd，日志 agentd.log
```

## 架构

```
浏览器 (127.0.0.1:8787 静态页)
 ├── goldscale（开源）── 行情/回测/信号/模拟盘/风控/记忆插件/前端插件机制
 │        ▲ 崩溃时由 agentd 自动拉起（10s 探活 ×3 → 杀旧 → nohup 起）
 └── AI 对话/教练 ──► goldscale-agentd（闭源，8788，Release 分发）
                       ├── pi 会话托管 · Origin 闸门 · 自愈监督
                       ├── 记忆网关（读写经 agent，判重裁决）
                       └── 能力任务口 /api/agent/task
```

**故障域分离**：外围功能是插件，可以炸；AI 核心独立，负责诊断与拉起。
没有 AI 核心，外围照常运转——这就是"开源外围 + 闭源核心"的边界。

### 功能 = 插件

前端插件是目录，**agent 新建一个目录 = 产品多一个页面，无需重编译**：

```
plugins/
├── index.json               # 静态注册表（浏览器不能列目录）
└── <name>/
    ├── manifest.json        # {"name","title","order","desc"}
    └── index.js             # window.Pages.<name> = {key,title,render(view),destroy}
```

启动时 app.js 按注册表逐个加载，**单个插件出错只 console.warn 并跳过，绝不拖死内置页**
（故障隔离已实测）。内置示例：`plugins/hello`（活模板）、`plugins/gold-glance`（AI 对话生成）。

## 投研回测（对齐量化平台）

策略页「投研回测」tab：

- **成本模型**：佣金（单边 %）+ 滑点 + 点差，全部计入净值与每笔明细
- **绩效指标 10 个**：总收益、年化、夏普、索提诺、卡玛、最大回撤、胜率、盈亏比、交易数、期望值 R
- **图表**：权益曲线 vs 买入持有基准 + 水下回撤面积图
- **月度收益表**（年 × 12 月 + 年度合计）、**交易明细**（出场原因徽章、R 倍数、持仓时长、费用拆分）
- **参数优化扫描**：勾选参数与取值（如 `40,50,60`），网格 ≤200 组合串行跑，按总收益降序、top1 金标
- **多策略对比**：一键串行回测全部启用策略，多线同图 + 对比指标表

回测纪律：逐 bar 前缀取数（无未来函数）、信号次根开盘成交、同根双触保守按止损；数据不足明确报错，**绝不编造**。

### 条件编写（策略页）

策略的买卖逻辑由**可视化行编辑器**拼装（做多入场 / 做空入场 / 出场三组）：

- 每行：`连接符 + 指标 + 运算 + 值`（指标 13 种：收盘价、EMA20/50/200、布林三轨、RSI、ATR、N 日高低、涨跌幅、偏离度；运算含上穿/下穿）
- AND/OR 严格左结合；空组 = 回落默认五步判定（存量策略零回归）
- **8 个经典模板**一键套用：均线金叉/死叉、多头排列、RSI 超卖超买、突破 20 日高、跌破 20 日低、深度回踩
- 条件即信号：信号判定、回测、参数优化共用同一套求值器

## AI 能力

| 能力 | 说明 |
|---|---|
| 结构化研判 | 读多周期行情 → 单轴仪表盘（0-100，越高越看多）+ 四模块 + 多空两套点位 + 风控裁决 + 思考过程；AI 定方向，**代码管风控**（手数/盈亏比/点差/日单数/时段一律代码说了算） |
| Agent 对话 | pi agent（每会话常驻），可 bash、读写文件、调本机 API 与产品工具；开发者工作流由闭源核心随二进制播种 |

对话入口：顶栏「询问 AI」（F2 或 Ctrl+K）右侧栏唤出，主内容挤压让位，边看行情边聊。

## 数据源与真实原则

| 用途 | 主源 | 降级链 |
|---|---|---|
| K 线 | xaus.com | 旧缓存（标 stale）→ 报错 |
| 现价 | xaus.com | gold-api.com → standardbullion.com → 旧价（标 stale） |

- 两层缓存（内存 TTL + 磁盘落盘）+ 后台续期真回源，页面请求基本零等待
- 上游断更按 `as_of` 年龄自动标注「K 线源自 HH:MM 起未更新」
- K 线陈旧而现货新鲜时，追加一根**现货合成根**（只表达此刻价、不编路径、不入缓存），让图与现价对齐
- 两源大幅背离时**拒绝跨源覆盖**（防假针）
- 三个源全挂：有旧数据就标注显示，没有就直接报错——**绝不返回模拟或编造的数据**

## 风控闸门

开仓前逐项校验，任一不过直接拒绝：盈亏比下限、点差上限、日单数上限、交易时段、止损点数区间、重大事件封锁。
出场管理：TP1 平 50% 并保本、TP2 平 40% 启动 ATR 移动止损、余仓跟踪至反转。

### 开发

```bash
cargo build --release     # 双 bin，零警告
cargo test --release      # 75 个测试（金秤 66 + agentd 9）
node --check js/pages/<改过的文件>.js
```

前端改动刷新即可；后端改动需重启（`bash start-all.sh` 会同步二进制）。数据在 `data/`（设置、账本、行情缓存），**服务运行时勿手改**（内存整体覆盖写）。
