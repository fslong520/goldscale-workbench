# 以机制辅助普通人克服人性弱点 · 设计文档

> 投资是反人性的：普通亏损大多不是因为不懂技术，而是败给追涨杀跌、死扛回吐、报复性交易、
> 过度自信与不复盘。本文档定义金秤的行为干预机制框架——**把意志力问题变成账户规则问题**。
> 原则：机制默认温和、可关、不替用户做决定；硬闸只守钱，不挡学习。

## 一、人性弱点 → 场景对照

| 弱点 | 行为金融学称谓 | 在金秤的典型场景 |
|---|---|---|
| 追涨杀跌 | FOMO / 从众 | 价格急拉时忍不住追，急跌时恐慌砍 |
| 死扛不止损 | 损失厌恶 | 浮亏贴着止损却期待反弹，越亏越拿 |
| 赢了跑太快 | 处置效应 | 浮盈 1R 就落袋，让利润跑不出来 |
| 亏了马上干回来 | 报复性交易 | 平亏单 5 分钟内又开仓，越做越小周期 |
| 连赢后加仓 | 过度自信 | 三连赢后手数翻倍，一把亏光前三把 |
| 随手开仓 | 冲动决策 | 没计划没依据，"感觉要涨"就点 |
| 从不复盘 | 认知吝啬 | 亏了归咎运气，同一错误反复犯 |
| 盯盘情绪化 | 注意力偏差 | 分时波动牵着情绪，频繁改主意 |

## 二、五层机制框架

### L1 预算约束（事前 · 把规则写进账户）
- **今日可亏额度**：权益 × 日风险预算（如 2%）→ 总览/开仓表单常驻显示「今日还可亏 $X」，
  用尽即当日锁仓（硬闸已有日单数，升级为**钱的口径**）。
- **单笔风险封顶**：手数建议一律由公式算（已落地），封顶值不可被 UI 绕过。
- **连赢不放大**：连续盈利 N 笔后，建议手数维持原风险并在计划卡注「近期连赢，建议维持仓位」。

### L2 冷却与拦截（事中 · 给冲动装刹车）
- **亏损冷却期**：平掉一笔亏损单后的 T 分钟（默认 15，可配）内开仓 → 强制确认弹层：
  「刚经历亏损，X 分钟内交易的胜率显著更低，仍要继续吗？」（可关，但默认开）。
- **快速连开拦截**：同 5 分钟第 3 笔 → 升级为红字确认。
- **无计划不开仓（可选模式）**：开启后，该策略无未过期计划卡时开仓 → 提示先生成计划
  （计划卡已落地，此为其上的闸）。

### L3 提醒纠偏（事中 · 替眼睛站岗，替嘴喊该喊的）
- **到价提醒**（已落地）：机械执行，不带情绪。
- **盈利回吐警报**：浮盈从峰值回撤超过设定比例（如从 2R 回到 0.8R）→ 横幅+响铃：
  「利润正在回吐，按计划该移动止损了」。
- **止损催促**：持仓且现价距止损 < 0.3×ATR 而止损未挂在结构位 → 一次性提醒。
- **FOMO 偏离提示**：现价距入场区偏离超阈值时，计划卡提示「已偏离计划 X%，不追，等回踩」。

### L4 复盘内化（事后 · 让每次亏损变成下次的免疫力）
- **亏损归因**（已落地）：每笔亏损一句人话归因。
- **模式聚合周报**：每周汇总归因关键词 →「本周 3 亏中 2 次是逆势抄底」，写入记忆。
- **重复错误拦截（杀手锏）**：开仓时把当前场景（方向/位置特征）与记忆中的近期归因比对，
  命中则在计划卡顶部黄条提示：「你在重复本周已犯 2 次的错误：逆势抄底。」
  ——依赖已落地的 respire 记忆（同一条库，AI 可读可写）。
- **月度体检**：胜率/盈亏比/最大回撤/错误 TOP3，一段 AI 总结，存为可翻阅的历史。

### L5 伙伴人设（贯穿 · AI 的嘴要有立场）
- AI 研判与对话中：**连赢不吹捧、亏损不催单、用户想加仓时先给风控事实**。
- 提示词规范写入 AI 研判与对话的系统层：先说风险与失效条件，再谈机会；
  数据不利时明确说"这次条件不成立"，不迎合用户情绪。
- 用户连续违背 L2/L3 提示时，AI 主动复述其代价统计（事实，不说教）。

## 三、落地优先级

| 级 | 机制 | 依赖 | 状态 |
|---|---|---|---|
| P0 | 今日可亏额度（钱口径硬闸） | stats + 风控 gate | 待做 |
| P0 | 亏损冷却期 | positions + 前端确认层 | 待做 |
| P1 | 盈利回吐警报 / 止损催促 | 持仓轮询 + L3 框架 | 待做 |
| P1 | 重复错误拦截（记忆比对） | respire 召回 + 计划卡 | 待做 |
| P1 | 无计划不开仓开关 | 计划卡标记（已落地） | 待做 |
| P2 | 归因周报 / 月度体检 | 归因缓存 + 记忆聚合 | 待做 |
| P2 | L5 人设提示词规范 | AI 研判/对话 prompt | 待做 |
| — | 到价提醒 / 计划卡 / 亏损归因 / 建议手数 | — | **已落地** |

## 四、防打扰原则

1. 同类提醒 30 分钟内不重复；触发类只在跨过阈值时响一次。
2. 硬闸（钱）与软提示（话）分离：软提示永远可关，硬闸关需显式确认。
3. 所有干预都给**数字依据**（胜率/回撤/次数），不喊口号。
4. 模拟盘先跑机制，数据说话后再谈是否影响真实下单流程。
